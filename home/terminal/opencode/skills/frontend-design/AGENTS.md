# Skill Router: frontend-design

- Врубай `frontend-design`, когда просят сделать/переделать UI: страницы, секции, компоненты, лендинги, дашборды.
- Типовые триггеры: `design`, `ui`, `layout`, `landing`, `make it look better`, `redesign`.
- Не врубай для чисто backend/logics задач без визуального слоя.
