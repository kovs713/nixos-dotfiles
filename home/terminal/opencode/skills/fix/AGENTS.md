# Skill Router: fix

- Врубай `fix`, когда есть lint/format ошибки, pre-commit/CI фейл по стилю, или перед коммитом нужен быстрый санитайз.
- Типовые триггеры: `eslint`, `prettier`, `stylelint`, `format`, `lint`, `CI failed`.
- Не врубай, если задача про фичу/рефактор/архитектуру без проблем форматирования.
