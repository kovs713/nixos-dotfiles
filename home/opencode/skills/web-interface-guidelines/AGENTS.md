# Skill Router: web-interface-guidelines

- Врубай `web-interface-guidelines`, когда нужно сделать UI-аудит по accessibility/usability/performance и дать список нарушений по файлам.
- Типовые триггеры: `ui review`, `a11y audit`, `web guidelines`, `check compliance`, `design QA`.
- Не врубай для реализации фичи без запроса на аудит соответствия.
