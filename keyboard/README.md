# corne v4

`corne-v4.vil` is the layout. this is the readable copy — if the two disagree,
the .vil wins.

3 layers. home row mods on `a s d f` / `j k l ;` [⌘ super/command, ⌥ alt/option, ⇧ shift, ⌃ ctrl], tap
after 200ms. `⇧x` is shift + that key, so `⇧{` is shift + `[`. `mo1` / `mo2`
are the layer keys.
